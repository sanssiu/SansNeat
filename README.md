# SansNeat 🍕🍔

SansNeat is a food delivery and ordering web application migrated to a fast, modern React + Vite application with Tailwind CSS.

## Features
- **Browse & Filter**: Select popular food categories (All, Pizza, Burger, Sandwich), search meals, and filter by price.
- **Popular Food Menu**: View curated dishes with pricing, descriptions, ratings, and instant add-to-cart.
- **Sans Preferred**: Explore featured promotional deals and seasonal banners.
- **Cart & Dynamic Pricing**: Real-time quantity adjustments, automatic delivery fee and subtotal calculations.
- **Instant Checkout & Order Tracking**: Place orders and track their delivery progression (Confirmed, Preparing, Out for Delivery, Delivered).
- **Favorites / Wishlist**: Save favorite foods and move them straight to cart.
- **User Profile**: Account details, saved addresses, payment methods, and preferences.
- **Responsive Navigation**: Signature `#00C2FF` floating capsule navigation bar with badge counters and desktop mobile frame preview.

## Tech Stack
- **Framework**: React 19, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide Icons
- **Language**: TypeScript
